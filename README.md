# MDB Intelligence Dashboard

Dashboard interaktif pinjaman empat Multilateral Development Bank (World Bank, ADB, AIIB, IsDB) untuk Indonesia.

* Versi: V81 (data per 2 November 2026)
* Cakupan: 1.169 proyek dan 3.610 lokasi
* Sumber: World Bank Projects API, IATI (ADB dan IsDB), daftar proyek resmi AIIB

Data berasal dari basis data publik MDB, bukan dari catatan pinjaman Kementerian Keuangan. Nilai adalah komitmen saat persetujuan, bukan pencairan.
